# Step 01: Go の基本

ゴール: 変数・関数・スライス・`switch` に触れる。

## なぜここから？

チームのコードを読むとき、まず出てくるのは「関数」「構造体」「エラー」「ループ」です。
フレームワークより先に、言語そのものの感覚を掴みましょう。

## やってみよう

```bash
make step1
# または
go run ./steps/01-hello
```

## 読むポイント

- `:=` は型推論付きの短い宣言
- `[]string` はスライス（可変長の配列っぽいもの）
- `switch` は break 不要（Go では自動で抜ける）

## 演習

2. `describeStatus` に `blocked` を追加する
